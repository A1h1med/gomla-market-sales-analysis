# تحليل مبيعات جملة ماركت

مشروع لتحليل بيانات المبيعات بهدف فهم أداء المبيعات واستخراج مؤشرات تساعد في اتخاذ قرارات أفضل.

## 🎯 أهداف المشروع

* تحليل أداء المبيعات عبر الفترات الزمنية.
* تحديد أكثر المنتجات والفئات تحقيقًا للإيرادات.
* تحليل أداء العملاء والمبيعات المتكررة.
* مقارنة المبيعات بين الفترات المختلفة.
* إنشاء مؤشرات أداء رئيسية (KPIs) لمتابعة أداء المبيعات.

## 🛠️ الأدوات والتقنيات

Python / Pandas — تنظيف وتجهيز البيانات.
Power BI — إنشاء Dashboard تفاعلية وعرض النتائج.

## 📊 التحليلات

يتضمن المشروع مجموعة من التحليلات، مثل:

* إجمالي الإيرادات.
* عدد الطلبات.
* عدد العملاء.
* متوسط قيمة الطلب.
* نمو الإيرادات.
* مقارنة الإيرادات مع الفترة السابقة.
* تحليل المبيعات حسب الفئة.
* تحليل المبيعات حسب الوقت.
* تحليل العملاء وتكرار الشراء.

## 📈 Dashboard

تم إنشاء Dashboard تفاعلية باستخدام Power BI لعرض أهم مؤشرات وتحليلات المبيعات بطريقة سهلة وواضحة.
